## What Auto Sheet Does

Auto Sheet provides a small, browser-accessible workspace for animation timesheet data. Load a CSV file and the tool displays its contents as a sheet preview, allowing animators and production teams to inspect timing information without leaving the browser.

After reviewing the imported sheet, users can export the visible preview as an image. Because the application runs on the web, it can be opened without installing a separate desktop program or dedicated animation software.

## Frequently Asked Questions

### What type of user is Auto Sheet designed for?

It is intended for anyone who needs to inspect animation timesheet data and create an image version of the resulting sheet.

### Is a desktop installation necessary?

No separate desktop installation is required. Use the hosted build in a browser, or open the HTML project from a local copy.

### Which import format is supported?

The documented input format is CSV.

### How can I export an image?

Import the CSV, verify the generated sheet preview, and select the image export function supplied by the interface.
